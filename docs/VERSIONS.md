# Reinminder 版本记录

版本号格式：`功能版本.编译号`，例如 1.0.3 = 1.0 功能版本的第 3 次编译。功能版本写在根目录的 `VERSION` 文件里。

## v1.4

- **拖拽设为子任务**：长按一个任务，拖到另一个任务上松手，前者就成为后者的子任务（今天页和日程页都可以）。子任务下面不能再放子任务；已经有子任务的任务不能被拖成子任务。子任务的详情页可以“移出”主任务。
- 日程页的任务行改成一行：标题 · 主题 · 时间（日期看上面的分组标题）。已完成列表也是一行。
- 列表里不再显示重复频率（今天页、日程页都是），点进任务能看到。

## v1.3

- 列表里不再显示“提前 X 小时”；主题改成浅蓝色加边框的小标签，放在日期后面（今天、日程、已完成、子任务、详情页都一样）。

- 今天页“即将到来”：显示明天起 7 天内的全部任务（不再限 6 条），每行前面也有圆圈，可以点击完成；字号和“已过期”“已完成”一致。
- 完成主任务时，如果还有未完成的子任务，会先弹出确认，确认后一起完成（存档或删除跟主任务一样）。从通知上点“完成”时没法弹确认，会直接一起完成。

- **子任务**：在任务详情的提醒下面点“添加子任务”，新建页和普通任务一样（默认用主任务的日期、时间和主题）。子任务在各个列表里正常显示，标题后面用蓝色小字标出主任务名；详情页顶部可以点回主任务。只支持一层。删除主任务时，它的子任务一起删除。
- **日程列表筛选**：顶部加“★ 重要”（只看重要）和“主题 ▾”（下拉选一个主题）。
- **月历**：有重要任务的日子用橙色星标，代替圆点。
- 同一天里重要的排在前面，在日程页也生效。

## v1.2

- **完成方式**：点任务前面的圆圈，可以选“推迟到明天 / 完成并存档 / 完成并删除”。
  - 完成并存档：打勾后移到“已完成”，不划线；可以随时恢复。
  - 完成并删除：今天划线显示，半夜自动删除；当天再点圆圈可以撤销。
  - 重复事件只有“推迟到明天 / 完成本次”：这次记入已完成，系列跳到下一次。删除整个系列在编辑页。
- **已完成列表**：今天页底部（默认折叠，列出全部存档，最近完成的在前），日程页新增“已完成”标签，都可以恢复。
- 列表不再响应左右滑动。通知上的按钮：完成存档、完成删除、稍后（重复事件：完成本次、稍后）。
- **自定义重复**：每 X 日 / 周 / 月。按月重复时，31 号在小月落到月末。一句话里写“每2周”“every 3 months”也能识别。
- **提醒默认准时**：提前 24 / 12 / 1 小时和自定义都是可选项，什么都不选就是准时提醒。
- **重要**：列表里标题前有橙色星标；同一天里重要的排在前面，同一重要程度按时间排。
- **闹钟式提醒**：开关移到新建页“重要”下面。到事件时间后每 10 分钟提醒一次（普通通知加提示音），直到完成、推迟或修改时间。不再全屏。
- 设置里去掉“稍后提醒”，通知上的“稍后”固定为 10 分钟。

## v1.1

- **主题**代替分类：可以新建、改名、删除（删除后事件保留，只是没有主题）。1.0 的六个分类自动变成同名主题，已有事件不受影响。
- **新建 / 编辑合并成一页**，不再有“更多设置”。从上到下：内容；时间（日期、时间、重复，去掉了全天）；提醒（提前 24 小时 / 12 小时 / 1 小时 / 自定义日期和时间，单选）；主题；重要。
- 内容里写了“周五下午3点”“#健康”这类词时，下面会出现“识别到……点击填入”，点一下自动填好时间、重复、主题、重要。
- 去掉多选提醒、默认提醒设置。
- 设置：语言改成和其他选项一样的一行；不再显示隐私和提醒可靠性两张卡片（功能不变）。
- 备份文件包含主题（格式 2），仍能导入 1.0 的备份。

## v1.0

- 今天：已过期（右滑完成、左滑或按钮推迟到明天）、今天的事件（可勾选完成）、未来 7 天
- 日程：月历（有事件的日子显示圆点，点选查看当天）和未来 60 天列表
- 快速记录：一句话识别日期、时间、重复、#分类、! 重要，中英文都支持；提醒可多选；可进入完整编辑（1.1 起合并进新建页）
- 详情与编辑：日期、时间或全天、重复（每天 / 每周 / 每月 / 每年）、多个提醒、闹钟式提醒、分类、重要、备注；改重复事件的时间时可选“仅这一次”或“以后每次”
- 提醒：精确闹钟；通知上有“完成”和“稍后”；闹钟式提醒全屏并持续响铃；重启、更新、改时间或时区后自动重新登记
- 设置：中文 / English、隐私说明、提醒可靠性检查（通知、精确闹钟、电池优化白名单、测试提醒）、默认提醒、分类、备份导出导入（默认加密）
- 折叠屏展开：今天页左边列表、右边详情
- 隐私：无网络权限、不进云备份和换机传输、无统计
